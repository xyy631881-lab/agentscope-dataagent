## 阶段 1：基础对话（5 分钟，验证能跑通）

**目标**：确认 Agent 能响应、看到 LLM 流式输出。

在聊天框依次输入：

| 步骤 | 输入                                           | 预期看到                                                 |
| ---- | ---------------------------------------------- | -------------------------------------------------------- |
| 1    | `你好`，你现在用的是哪家的大模型，叫什么名字？ | Agent 流式回复一段中文问候                               |
| 2    | `你能做什么？`                                 | Agent 列出自己的能力（数据分析、SQL 查询、图表等）       |
| 3    | `列出所有可用的数据源`                         | Agent 调用 `list_data_sources` 工具，返回 `analytics_db` |

**关注点**：
- 文字是**一个字一个字蹦出来**的（SSE 流式），不是一次性出现
- 第 3 步会看到工具调用的过程（前端会显示 `调用工具 list_data_sources`）

> 第 3 步如果卡住或超时，可能是 DashScope API Key 没配好。检查 [application-mysql.yml](file:///e:/demo/agentscope-dataagent/src/main/resources/application-mysql.yml) 里的 `dataagent.dashscope.api-key`。

## 阶段 2：数据分析核心流程（10 分钟，重点体验）

**目标**：完整体验 Agent 的 ReAct 循环（思考→调工具→观察→回答）。

依次输入：

| 步骤 | 输入                                        | 你会看到的 Agent 行为                              |
| ---- | ------------------------------------------- | -------------------------------------------------- |
| 1    | `analytics_db 里有哪些表？各表结构是什么？` | 调 `describe_table` 工具，返回 4 张表的字段定义    |
| 2    | `查询 products 表前 5 条记录`               | 调 `run_sql_preview`，返回 5 条商品数据            |
| 3    | `查询最近 7 天的日销售额`                   | 调 `run_sql_preview` 查 `daily_sales`，返回数据    |
| 4    | `把刚才的销售数据画个折线图`                | 调 `render_chart`，生成 Vega-Lite 图表（前端渲染） |
| 5    | `哪个品类的销售额最高？给出分析报告`        | 综合 SQL + 推理，生成文字报告                      |

**关注点**：
- Agent 会先**思考**（显示 thought）再调工具，不是直接执行
- 每次工具调用都有 `tool_call` 和 `tool_result` 两个事件
- 第 4 步的图表会直接在聊天界面渲染出来（不是返回 JSON）

**阶段 2 是理解 AgentScope 的核心**——这就是 ReAct 模式的完整循环：Reason（思考）→ Act（调工具）→ Observe（看结果）→ 循环直到得出答案。

## 阶段 3：Plan Mode 和子 Agent（10 分钟，进阶能力）

**目标**：体验 Plan Mode（先规划再执行）和子 Agent 分发。

| 步骤 | 输入                                       | 预期                                                         |
| ---- | ------------------------------------------ | ------------------------------------------------------------ |
| 1    | `帮我分析用户表的年龄分布，并给出营销建议` | Agent 可能进入 Plan Mode，列出分析步骤等你确认               |
| 2    | （确认计划）                               | Agent 按计划执行，可能 `agent_spawn` 分发给 `report-writer` 子 Agent |
| 3    | `审查一下我刚才的 SQL 写得对不对`          | 可能触发 `code-reviewer` 子 Agent                            |

**关注点**：
- Plan Mode 会显示一个计划列表，**需要你点确认**才会执行
- 子 Agent 调用会显示 `agent_spawn` 工具，你能看到分发过程

> 这一步不一定每次都触发，取决于 LLM 的判断。如果不触发，换个复杂问题，比如 `对比本月和上月各品类的销售增长率，生成完整分析报告`。

## 阶段 4：多租户与分享（10 分钟，项目特色）

**目标**：理解这个平台和单机 ChatGPT 的本质区别——多租户隔离 + 能力沉淀。

### 4.1 创建自定义 Agent

1. 左侧菜单 → `Agent 配置` → 点 `创建 Agent`
2. 填入：
   - ID: `my-finance-agent`
   - 名称：财务分析师
   - 系统提示词：`你是一个专业的财务分析师，擅长解读财务数据...`
3. 保存后回到聊天页，切换到这个 Agent 对话

### 4.2 体验分享

1. 在 `Agent 配置` 页找到你刚创建的 `my-finance-agent`
2. 点 `分享` 按钮（👥 图标）
3. 添加一条分享：授权给某个用户 / 全员，权限选 `RUN`
4. 用另一个浏览器（或无痕窗口）注册新用户登录，看能否看到这个 Agent

### 4.3 看后台数据变化

在 IDEA 的 Database 工具里查 `agentscope_dataagent` 库：
```sql
SELECT * FROM dataagent_agent;          -- 看到你创建的 Agent
SELECT * FROM dataagent_agent_share;    -- 看到分享记录
SELECT * FROM dataagent_user;           -- 看到注册的用户
```

同时打开 Another Redis Desktop Manager 看 `db2`：
- 对话后会出现 `dataagent:session:xxx:agent_state` 这种 key
- 这就是多副本共享的 Agent 状态

## 推荐体验顺序

如果你时间有限，**重点体验阶段 2**——这是 Agent 平台的核心价值，能看到完整的工具调用链路。其他阶段是锦上添花。

体验过程中如果遇到：
- **Agent 不回复 / 一直转圈** → 多半是 DashScope API Key 问题，看 jar 控制台日志
- **工具调用失败** → 看日志里的 ERROR，通常是 SQL 或参数问题
- **想看 Agent 内部思考过程** → 看 jar 控制台，会打印完整的 ReAct 步骤
