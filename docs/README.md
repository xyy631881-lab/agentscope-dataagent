# AgentScope DataAgent 文档入口

> 基线版本：`2.0.0-SNAPSHOT`  
> 更新日期：2026-07-30  
> 读者：第一次接触本项目的开发者、测试人员、面试官和后续维护者。

本目录描述的是一个基于 AgentScope Java 2.0 的数据智能体平台。它不是单纯的聊天页面：平台把用户、Agent 定义、会话、工具调用、隔离工作区、技能市场、审批、模型连接、用量和运行记录组合成可治理的产品。

2. [02-功能方案与核心流程.md](02-功能方案与核心流程.md)：按功能拆解前后端方案、关键流程、权限和持久化边界。
3. [03-运行、测试与排障.md](03-运行、测试与排障.md)：本地启动、验证命令、已知问题、排障路径和近期修复记录。

## 本次文档基线已验证项

- `mvn test`：84 个测试成功，11 个既有跳过项，0 失败。
- `frontend/npm.cmd run build`：TypeScript 检查和 Vite 生产构建成功；产物写入 `src/main/resources/static/`。
- 私有 Agent 定义工作区按 `userId + agentId` 隔离；运行时、控制面和技能读取路径已统一。
- 技能删除后不再因“补齐基础技能”逻辑自动复活；技能列表请求禁用浏览器缓存。
- `/usage` 已成为统一入口：普通用户看个人数据，管理员可切换平台汇总与个人用量；`/admin/usage` 保留为兼容跳转。
- 工作台主内容区支持纵向滚动，长页面和运行记录不会因固定视口被裁掉。

## 事实与边界

文档中的“已实现”只表示代码和当前测试/构建证据支持该结论，不等价于生产级 SLA。尤其是多实例压测、真实外部 IM 通道、Skill 供应链安全、跨 MySQL/Redis/文件系统一致性和离线 Agent 评测仍需继续建设。
